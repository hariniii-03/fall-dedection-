# data/

Small, representative sample IMU captures only (a few examples per class,
for anyone browsing the repo to see the raw data shape). The full training
dataset lives in Edge Impulse (see Phase 4) — this folder is not a mirror
of it.

Raw per-session recordings from `tools/serial-data-logger.html` go in
`data/raw/`, which is git-ignored — copy 1-2 representative CSVs per
class here (in `data/`, not `data/raw/`) instead.
